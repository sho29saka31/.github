# .github

このリポジトリは GitHub の [デフォルトコミュニティヘルスファイル](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) 用のリポジトリです。

ここに置いたテンプレート・ドキュメントは、同じアカウント配下の各リポジトリが独自のファイルを持たない場合に自動的に適用されます。

## 含まれるもの

- Issue フォーム ([.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE)) — bug_report / feature_request / question / custom の4種類（YAML形式）
- Pull Request テンプレート ([.github/PULL_REQUEST_TEMPLATE](.github/PULL_REQUEST_TEMPLATE)) — feature / fix / refactor / release / hotfix / chore / docs / short の8種類。PR作成時に `?template=` パラメータや「Choose a template」から選択できます
- コントリビューションガイド ([CONTRIBUTING.md](CONTRIBUTING.md))
- サポート情報 ([SUPPORT.md](SUPPORT.md))
- 行動規範 ([CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)) — Contributor Covenant v3.0
- セキュリティポリシー ([SECURITY.md](SECURITY.md))

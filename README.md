# .github

このリポジトリは GitHub の [デフォルトコミュニティヘルスファイル](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) 用のリポジトリです。

ここに置いたテンプレート・ドキュメントは、同じアカウント配下の各リポジトリが独自のファイルを持たない場合に自動的に適用されます。

## 含まれるもの

- Issue テンプレート ([.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE))
- Pull Request テンプレート ([PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md))
- コントリビューションガイド ([CONTRIBUTING.md](CONTRIBUTING.md))
- サポート情報 ([SUPPORT.md](SUPPORT.md))
- 行動規範 ([CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md))
